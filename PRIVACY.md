# Privacy Policy

Last updated: July 27, 2026

RMSNKRS eBay Assistant is a personal, local-use integration operated by Ryan Makadok.

- The integration accesses eBay account data only after the account owner grants permission through eBay OAuth.
- It uses that access solely to perform eBay actions requested by the account owner.
- OAuth credentials are stored locally on the owner's computer and are not sold, shared, or used for advertising.
- The integration does not operate a separate user database or persist eBay marketplace user data on a remote service.
- Access can be revoked at any time from the connected eBay account's third-party application settings.

Questions about this policy may be submitted through the repository's GitHub issue tracker.
